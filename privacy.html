Privacy Policy

Wuevas, Tampa, Florida, USA. Last updated October 2, 2026.

Who we are

Wuevas is a small software and business-systems company. This page explains how we handle data in our internal tools. Questions: admin@wuevas.com.

The Wuevas Hermes Agent (Google integration)

The Wuevas Hermes Agent is a private assistant used only by Wuevas’s owner and staff. It is not offered to the public and has no other users. It connects to a Google account owned by Wuevas through Google’s OAuth sign-in, and only to the Google services the owner approves on the consent screen (for example Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs and Google Contacts).

What it does with that data

It reads, searches, drafts and organizes the Wuevas account’s own email, calendar events, files and spreadsheets to run Wuevas business operations (for example tracking leads in a spreadsheet or summarizing the inbox). It acts only on requests from Wuevas’s owner or staff.

What we do not do

  • We do not sell Google user data or share it with advertisers or data brokers.
  • We do not use Google user data for advertising, and we do not use it to build a product for the public.
  • We do not allow humans to read Google user data except where needed to run Wuevas’s own business, for security, or where the law requires.

AI processing

To perform a request, the relevant content may be sent to AI model providers acting as service providers for that task only. We do not permit those providers to use it to advertise to anyone.

Storage and security

Access tokens are stored on a private server controlled by Wuevas. We keep only what is needed to run the tools and delete data we no longer need.

Google API Services User Data Policy

Wuevas’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

You can revoke the app’s access at any time at myaccount.google.com/permissions. To ask a question or request deletion of data we hold, email admin@wuevas.com.

Changes

We will update this page and its date if our practices change.
